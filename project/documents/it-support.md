# 1. Password Reset Process

## Purpose
Help users securely reset their account password.

## Prerequisites
- User identity must be verified.
- User must have access to the registered email or mobile number.

## Steps

1. Verify the user's identity.
2. Open the Identity Management Portal.
3. Search for the user's account.
4. Select **Reset Password**.
5. Generate a temporary password or send a password reset link.
6. Ask the user to log in using the temporary password.
7. Instruct the user to create a new password that meets company policy.

## Password Policy

- Minimum 12 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one number
- At least one special character
- Must not match previous passwords

### Payroll Portal Password Reset

If an employee needs to reset their Payroll Portal password (self-service):

1. Open the Payroll Portal sign-in page.
2. Click “Forgot Password”.
3. Enter the registered company email or mobile number.
4. Complete OTP/MFA verification if prompted.
5. Use the email link to set a new password.
6. Ensure the new password meets policy (min 12 chars, uppercase, lowercase, number, special character).

If the reset email is not received within 10 minutes, check spam or contact:
- IT Service Desk: servicedesk@company.com
- Payroll Team: payroll@company.com

# 2. VPN Configuration

## Purpose

Configure secure VPN access for remote employees.

## Requirements

- Company VPN client installed
- Active user credentials
- MFA enabled

## Configuration Steps

### Windows

1. Download the approved VPN client.
2. Install the application.
3. Open the VPN client.
4. Enter:
   - VPN Server Address
   - Username
   - Password
5. Complete MFA authentication.
6. Click **Connect**.

### macOS

1. Install the VPN client.
2. Configure the VPN profile.
3. Enter credentials.
4. Complete MFA verification.
5. Connect successfully.

## Troubleshooting

- Verify internet connectivity.
- Confirm VPN server address.
- Ensure account is active.
- Restart the VPN client.
- Reboot the computer if needed.

# 3. Software Installation Requests

## Purpose

Handle employee requests for new software.

## Approval Process

1. User submits a software request.
2. Manager approves the request.
3. Security team validates software.
4. IT installs the application.

## Installation Steps

1. Verify approval.
2. Download software from an approved source.
3. Install using administrator privileges.
4. Restart the computer if required.
5. Verify successful installation.

## Information Required

- Software name
- Version
- Business justification
- Device name
- Operating system

# 4. MFA (Multi-Factor Authentication) Setup

## Purpose

Enable additional security for user accounts.

## Supported Methods

- Microsoft Authenticator
- Google Authenticator
- SMS verification
- Hardware security key

## Setup Steps

1. Log into the company portal.
2. Navigate to **Security Settings**.
3. Select **Enable Multi-Factor Authentication**.
4. Choose an authentication method.
5. Scan the QR code using the authenticator app.
6. Enter the verification code.
7. Save backup recovery codes.

## Verification

- Log out.
- Log back in.
- Confirm MFA prompt appears.
- Complete authentication.

# 5. Guest Wi-Fi Access

## Purpose

Provide temporary internet access for visitors.

## Eligibility

- Visitors
- Contractors
- Vendors
- Interview candidates

## Access Process

1. Create a guest account.
2. Set an expiration date.
3. Share:
   - Wi-Fi SSID
   - Temporary password
4. Inform the guest of acceptable use policies.

## Restrictions

- Internet access only
- No internal network access
- Time-limited account
- Activity may be monitored

# 6. Email Configuration on Mobile

## Supported Platforms

- Android
- iPhone (iOS)

## Configuration Steps

### Android

1. Open the Email or Outlook app.
2. Select **Add Account**.
3. Enter company email address.
4. Enter password.
5. Complete MFA verification.
6. Allow required permissions.
7. Finish setup.

### iPhone

1. Open **Settings**.
2. Select **Mail**.
3. Tap **Accounts**.
4. Tap **Add Account**.
5. Choose Microsoft Exchange or the appropriate provider.
6. Enter email credentials.
7. Complete MFA.
8. Save settings.

## Troubleshooting

- Verify internet connectivity.
- Confirm account credentials.
- Check mailbox storage quota.
- Remove and re-add the account.
- Contact IT if synchronization fails.

# Escalation Guidelines

Escalate the issue if:

- Password reset fails repeatedly.
- VPN authentication continues to fail.
- Software requires elevated approval.
- MFA cannot be registered.
- Guest Wi-Fi cannot be provisioned.
- Mobile email synchronization continues to fail after troubleshooting.
